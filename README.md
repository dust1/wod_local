# WOD三字母的本地实现

基于WOD（world-of-dungeons）的本地实现，由于法律原因具体的游戏道具数据不便公开，需要另外想办法，当前是对WOD的配装以及战斗模拟的实现


## 用途
相当于单机版，可以自由配装以及导入已有的角色卡，并通过地城探索的方式来模拟战斗，方便战术排轴。

> 战术录入12个人的人物卡就是另外的工作量了
