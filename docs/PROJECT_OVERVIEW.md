# 项目概览

本项目是 WOD 的本地配装与战斗模拟工具，不是独立运营的成长型游戏。用户建立或导入英雄、调整属性技能和装备、配置行动，运行地城模拟并阅读战报，再修改构筑重试。`WOD教科书计划.docx` 解释原版游戏的规则与背景，是模拟规则的参考，不代表本工具要实现原版的奖励和经济循环。**模拟探索不发放经验、金币或物品，也没有地城等级、准备时间或重复探索次数限制。**

## 当前可玩的流程

注册/登录 → 创建并选择英雄 → 查看属性、训练技能、配置装备与行动顺序 → 选择地城即时探索 → 按楼层/房间模拟战斗 → 查看战报。英雄还可管理角色/团队仓库、购买市场物品、导入人物卡；管理员可配置召唤物。角色、仓库、设置和战报持久化于 `data/game.sqlite`。界面以 `src/main.jsx`、`src/App.jsx` 进入；API 以 `server.mjs` 进入。

核心是角色实例计算、行动设置、战斗状态机、效果账本、命中/伤害/资源公式、地城探索与战报。`game/engine/simulate.mjs` 运行回合阶段；`application/battle-service.mjs` 将账号英雄、设置、目录技能、遭遇配置装配成战斗并保存。地城不是可自由移动的地图；`gamedata/overrides/dungeon-encounters.mjs` 只组织模拟房间，三个本地地城的敌方均为固定训练木桩，不追求原版怪物数值。交互主要是菜单、表单和战报，没有实时移动、NPC 对话、任务链、音频、动画或对象池。木桩行动由战斗计划/策略执行，不是独立寻路 AI。

八项属性、技能等级、装备/套装和效果共同生成战斗数值。体力/法力、先攻、命中、闪避、伤害、效果持续与叠加都由 `game/` 计算。配装检查英雄唯一（当前角色至多一件）和队伍唯一（当前账号所有角色合计至多一件）。物品“剩余使用次数”每次调用减少，耗尽后本次模拟中不可再用，保存的仓库不变；“每地城可使用次数”跨房间/楼层累计，“每战斗可使用次数”在每个新房间重置。装备耐久不属于本工具规则。现有角色编辑功能仍使用经验和金币字段；这些资源不会因模拟探索而增加。技能、职业、种族和物品目录来自 `gamedata/generated/` 及 SQLite；遭遇配置目前规模较小。战斗失败会结束本次模拟并留下战报。界面组件只显示并提交选择。

角色仓库中的传古遗物可打开“镶嵌”页面，查看孔位、现有符文、物品原有效果与组合追加效果。材料从当前角色仓库的 20 种传古符文实例中选择；每枚符文消耗一个实例。组合按种类和数量匹配，不计顺序，并要求遗物极性对应；未匹配或极性不符时无追加效果。拆卸会清空孔位但不返还符文。遗物移入团队仓库时保留镶嵌记录，装备后组合效果进入角色实例与战斗，卸下后失效。

## DOCX 与实现的差异（待确认，不自动改规则）

- DOCX 是原版 WOD 新手教程，不是本仓库的完整需求。它描述固定等待约 10 小时、一次加速、限时地城与任务路线；本工具的模拟探索同步结算、可重复运行，不实现这些进入或等待约束。数据库中的地城等级与准备时间是来源元数据，不用于限制模拟。
- 文档描述原版通过战利品、经验和金币成长；本工具明确不结算或发放探索奖励。装备唯一性和三种使用次数按本地配装/模拟口径执行，耗尽只影响当前模拟；原版伤害后装备耐久不纳入本工具。
- DOCX 描述多人团队、联盟、称号、论坛、NPC/酒馆信息与 PVP 设置；当前团队来自同一账号的英雄列表，相关原版社交和联盟系统没有完整实现。
- DOCX 的“丁图安蛮族冒险者”、500 初始经验、免费转职、新手/专家设置、精通重置点、技能金币花费等属于原版教程；本地创建、训练和设置按当前服务端实现，逐项差异须在开发具体功能时核对。
- DOCX 详细说明六站位、回合前→自然回复→先攻→主回合、耗材、效果延迟和同源不叠加；代码有对应模型与测试，但导入内容的覆盖度和未证实规则以 `gamedata/rules/rule-questions.mjs`、策略注册表为准。
- 本地实现另有文档未介绍的账号认证、人物卡导入、规则诊断、召唤配置、管理员模式和数据库契约校验。原版怪物与地城遭遇不作为本工具的还原目标；固定木桩数值只是本地测试配置。原版 HTML 战报导入已移除；本地模拟战报仍可查看。

推进方向是提高配装计算、战斗模拟和本地战报的可信度。发现具体技能、物品效果或计算差异时，再修改公式和相关代码；不以原版战报导入作核验门槛。任何 DOCX/代码冲突先记差异，不直接改成原版描述；不要为探索增加奖励经济循环。
